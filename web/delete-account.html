앱에서 계정 삭제

당당하게 앱에 로그인한 후 다음 경로를 통해 직접 회원탈퇴를 진행할 수 있습니다.

마이페이지 → 보안 및 개인정보 → 회원탈퇴

회원탈퇴가 완료되면 해당 계정과 연결된 개인정보 및 서비스 데이터가 삭제됩니다.

계정 삭제 시 삭제되는 데이터

회원탈퇴 또는 계정 삭제 요청이 처리되면 다음 데이터가 삭제됩니다.

  • Firebase Authentication 사용자 계정
  • 회원 및 프로필 정보
  • 닉네임 관련 정보
  • 혈당 기록
  • 식단 기록
  • 사용자가 등록한 식단 이미지
  • 사용자가 등록한 프로필 이미지
